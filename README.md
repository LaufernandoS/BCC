# 🇧🇷 Português

## Sobre

Este repositório reúne materiais produzidos durante minha graduação em Ciência da Computação no Instituto de Matemática e Estatística da Universidade de São Paulo (IME-USP).

O objetivo é centralizar projetos, listas de exercícios, resumos, implementações, relatórios e demais artefatos desenvolvidos ao longo das disciplinas.

> ⚠️ Os materiais foram produzidos para fins acadêmicos e de estudo. Eles podem conter simplificações, erros ou soluções alternativas em relação ao conteúdo oficial das disciplinas.

---

## Disciplinas

### MAC0216 — Técnicas de Programação I

Introdução ao desenvolvimento de software em ambientes Unix/Linux, programação em C, automação, ferramentas de desenvolvimento, controle de versão e boas práticas de programação.

**Principais tópicos**
- Linguagem C
- Linux e Shell Script
- Git
- Makefiles
- Depuração e testes
- Modularização de software

---

### MAC0338 — Análise de Algoritmos

Estudo de técnicas de projeto e análise de algoritmos, com foco em eficiência computacional e complexidade.

**Principais tópicos**
- Análise assintótica
- Recorrências
- Divisão e conquista
- Programação dinâmica
- Algoritmos gulosos
- NP-completude

---

### MAC0350 — Desenvolvimento de Sistemas de Software

Fundamentos de engenharia de software e construção de sistemas de médio porte.

**Principais tópicos**
- Orientação a objetos
- UML
- Testes de software
- Refatoração
- Bancos de dados
- Padrões de projeto

---

### MAC0422 — Sistemas Operacionais

Estudo dos mecanismos internos dos sistemas operacionais modernos.

**Principais tópicos**
- Processos e threads
- Escalonamento
- Memória virtual
- Sincronização
- Sistemas de arquivos
- Comunicação entre processos

---

### MAC0460 — Introdução ao Aprendizado de Máquina

Fundamentos teóricos e práticos de Machine Learning.

**Principais tópicos**
- Regressão
- Classificação
- SVM
- Redes neurais
- Regularização
- Avaliação de modelos

---

### MAC0508 — Introdução ao Processamento de Língua Natural

Métodos computacionais para análise e geração de linguagem natural.

**Principais tópicos**
- Pré-processamento textual
- Modelos probabilísticos
- Classificação de textos
- Extração de informação
- Embeddings
- Modelos neurais

# 🇺🇸 English

## About

This repository contains materials developed throughout my undergraduate studies in Computer Science at the Institute of Mathematics and Statistics of the University of São Paulo (IME-USP).

It serves as a centralized archive for projects, assignments, notes, reports, implementations, and other academic work produced during the program.

> ⚠️ These materials were created for academic and learning purposes. They may contain simplifications, mistakes, or alternative solutions compared to the official course content.

---

## Courses

### MAC0216 — Programming Techniques I

Introduction to software development in Unix/Linux environments, covering C programming, automation, development tools, version control, and software engineering practices.

**Main topics**
- C Programming
- Linux and Shell Scripting
- Git
- Build Systems
- Debugging and Testing
- Software Modularity

---

### MAC0338 — Algorithm Analysis

Design and analysis of algorithms with emphasis on computational efficiency and complexity.

**Main topics**
- Asymptotic Analysis
- Recurrences
- Divide and Conquer
- Dynamic Programming
- Greedy Algorithms
- NP-Completeness

---

### MAC0350 — Software Systems Development

Foundations of software engineering and medium-scale software development.

**Main topics**
- Object-Oriented Programming
- UML
- Software Testing
- Refactoring
- Databases
- Design Patterns

---

### MAC0422 — Operating Systems

Study of the internal mechanisms of modern operating systems.

**Main topics**
- Processes and Threads
- Scheduling
- Virtual Memory
- Synchronization
- File Systems
- Interprocess Communication

---

### MAC0460 — Introduction to Machine Learning

Theoretical and practical foundations of machine learning.

**Main topics**
- Regression
- Classification
- Support Vector Machines
- Neural Networks
- Regularization
- Model Evaluation

---

### MAC0508 — Introduction to Natural Language Processing

Computational methods for understanding and generating natural language.

**Main topics**
- Text Preprocessing
- Probabilistic Models
- Text Classification
- Information Extraction
- Embeddings
- Neural Models
